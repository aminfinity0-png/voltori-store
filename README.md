# voltori-store (Upgraded)

This repo holds the upgraded **VOLTORI** storefront website, hosted on **GitHub Pages**.

## Live site
`https://aminfinity0-png.github.io/voltori-store/`

## What's Included
- `index.html` — Semantic storefront layout (Announcement bar, Sticky navbar, Hero, Shop & Filters, Desk Bundle, Why Voltori, FAQ Accordion, Contact & Newsletter, Quick View Modal, Cart Drawer, Express Checkout)
- `style.css` — Dark/Light theme system, responsive grid, glassmorphic header, drawer & modal transitions
- `script.js` — Product catalog (`PRODUCTS`), live search, category/wishlist filtering, sorting, multi-currency (`USD`, `INR`, `EUR`), free-shipping progress meter ($49 threshold), promo codes (`VOLTORI10`, `WELCOME15`), and checkout flow
- `assets/` — Studio product photography for every item and the hero banner

## How to change products
1. Open `script.js` on GitHub -> click the pencil (**Edit**).
2. Edit the `PRODUCTS` array at the top of `script.js` to add, remove, or update products and prices.
3. Commit your changes to `main` — GitHub Pages updates automatically in ~1 minute.
